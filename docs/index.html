A presentation director for your AI agent.

PPT Studio turns “make me a deck” into a real conversation. It asks one question at a time — audience, brand, your speaking voice, the actual research — confirms the story before touching design, and ships a self-contained 16:9 HTML presentation you can open, edit, and present anywhere.

Ten phases, in order

No blank-page guessing and no generic AI copy. Each phase has to close before the next one opens, and nothing gets designed until you have approved what it says.

  1. Audience discovery

    Who is in the room, what they already know, and the decision you need from them.

  2. Brand validation

    Reads the brand material you supply instead of asking for facts it can already see.

  3. Speaker voice

    Captures how you actually talk, so the slides sound like a person.

  4. Subject-matter research

    Works the topic as a domain expert and surfaces the evidence behind each claim.

  5. Narrative

    Builds the arc — context to decision — before a single layout exists.

  6. Content approval

    You sign off on the words. This is the gate to production.

  7. Visual exploration

    Compares isolated two- or three-slide microdecks without duplicate toolbars or controls over the artwork.

  8. Production

    Builds the full deck: text editing, save status, deep links, state-aware navigation.

  9. Motion

    Restrained animation that supports the point instead of performing.

  10. Final QA

    Re-validates the HTML after browser edits, so what you present is what you approved.

What you get

One file, no server

A fixed 16:9 self-contained HTML deck. No build step, no CDN, no broken link five minutes before you present.

Light, dark, and your brand

Three themes on a documented token contract, switchable from inside the deck.

Editable in the browser

Click text or a safe visual component to open a nearby toolbar for type, color, borders, radius, shadow, and opacity, with safe ranges and rendered QA.

Your content stays yours

The runtime is Apache-2.0 and carries discreet generator metadata — never a watermark on your slides.

Install

Pick your host. The package exposes a single canonical skill, ppt-presentation-studio, and needs no other presentation framework.

Claude Code

marketplace
claude plugin marketplace add intellbits/ppt-studio
claude plugin install presentation-studio@ppt-studio-marketplace
# Invoke: /presentation-studio:ppt-presentation-studio

Codex

marketplace

Register intellbits/ppt-studio as a marketplace, then install presentation-studio from ppt-studio-marketplace. Invoke it with $ppt-presentation-studio or let Codex select it automatically.

ChatGPT

skill upload

Upload ppt-presentation-studio-1.0.4-chatgpt.zip from Skills → Create → Upload from your computer. Availability and upload permissions depend on the user’s plan and workspace settings.

Claude Chat

skill upload

Download ppt-presentation-studio-1.0.4-claude.zip from the latest release and upload it under Customize → Skills. It appears as Presentation Studio by intell labs (part of intellbits.com); the archive holds the skill folder at its root and pulls in nothing external.

From source

local development
git clone https://github.com/intellbits/ppt-studio.git
cd ppt-studio
python3 scripts/validate_all.py   # cross-target checks
python3 scripts/build_release.py  # Codex + ChatGPT + Claude ZIPs in dist/

Then point the marketplace at the absolute repository path instead of intellbits/ppt-studio.
